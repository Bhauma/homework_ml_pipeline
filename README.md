# Практический пример интеграции AirFlow и MLFlow
- Этот проект демонстрирует, как с помощью Apache AirFlow можно автоматизировать запуск обучающих задач, а MLFlow — логировать и управлять экспериментами и моделями, обеспечивая end-to-end пайплайн в рамках MLOps.

## Структура проекта

- `dags/ml_pipeline_dag.py` — Определение DAG для AirFlow, который запускает процесс обучения модели.
- `mlflow_projects/train.py` — Скрипт для обучения модели с логированием гиперпараметров, метрик и сохранением модели через MLFlow.
- `mlflow_projects/MLproject` — Конфигурация MLFlow-проекта.
- `mlflow_projects/requirements.txt` — Зависимости для MLFlow-проекта.

## Инструкция по запуску

1. **Настройка AirFlow:**
   - Убедитесь, что у вас установлен Apache AirFlow.
   - Поместите директорию `practic/dags` в путь, указанный в конфигурации AirFlow (обычно `dags_folder`).

2. **Запуск MLFlow:**
   - Установите зависимости для MLFlow, выполнив:
     ```
     pip install -r practic/mlflow_projects/requirements.txt
     ```
   - Запустите MLFlow UI командой:
     ```
     mlflow ui
     ```
     По умолчанию MLFlow UI доступен по адресу `http://localhost:5000`.

3. **Запуск DAG:**
   - Запустите AirFlow Scheduler и Webserver.
   - В веб-интерфейсе AirFlow найдите DAG с именем `ml_pipeline` и активируйте его.
   - Запустите DAG, чтобы инициировать процесс обучения модели.

4. **Проверка результатов:**
   - После выполнения DAG проверьте MLFlow UI для просмотра логов эксперимента, метрик и сохраненной модели.
